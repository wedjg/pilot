## 1. 文档导引

### 1.1 文档目的

本文档对 PM Pilot 全部功能模块进行完整、无歧义的设计拆解，作为前端开发、测试用例编写和验收的唯一功能依据。架构决策和数据结构请分别参见《架构设计文档》和《数据模型文档》。

### 1.2 功能模块全景图

```text
PM Pilot 功能全景
├── M01 全局框架               # 导航、撤销、主题、隐私引导
├── M02 驾驶舱                 # 风险雷达、今日必做、健康度矩阵、里程碑、最近完成
├── M03 项目全景               # 项目列表、筛选、多选操作、休眠/归档管理
├── M04 项目工作台             # 看板视图、甘特图视图、快速指令栏、任务详情
│   ├── M04a 看板子模块
│   ├── M04b 甘特图子模块
│   └── M04c 任务详情子模块
├── M05 个人待办桌             # 跨项目待办聚合、专注模式、完成动画
├── M06 数据与档案             # 回收站、周报、复盘中心、导入/导出
└── M07 偏好设置               # 主题、默认截止时间、备份提醒、存储监控
```

### 1.3 术语定义

| 术语 | 定义 |
|:---|:---|
| **阻塞任务** | 状态为 `blocked` 的任务，其进度不可信，需解决依赖或外部问题后方可继续。 |
| **关键路径** | 项目依赖网络中决定最早完成时间的最长路径，基于标准 CPM 算法计算。 |
| **防欺骗进度** | 不隐藏真实完成百分比，但在关键路径阻塞时通过视觉锁定（琥珀条纹+🔒）表达风险。 |
| **快速指令栏** | 项目工作台中的自然语言快速创建任务输入框。 |
| **SLA 升级** | 阻塞超过 48 小时的任务自动提升为“急需介入”级别。 |
| **专注模式** | 隐藏全局导航，仅保留个人待办桌全屏视图的单屏模式。 |


## 2. M01 全局框架

### 2.1 顶部导航栏

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **导航项** | 固定显示：【驾驶舱】【项目】【待办】【档案】【设置】五入口。图标+文字形式（≥1440px）。 | 当前页入口高亮，其余为默认态。 |
| **深色模式跟随** | 导航栏背景与文字色随主题联动。 | 切换主题时无闪烁。 |
| **响应式兜底** | 视口 <1440px 时导航栏压缩，仅保留图标。 | 不做移动端适配，低于 1024px 显示“请使用更大屏幕”提示。 |

### 2.2 撤销/重做系统

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **快捷键** | `Ctrl+Z` 撤销，`Ctrl+Shift+Z` / `Ctrl+Y` 重做。`Shift+F` 切换专注模式。 | 全局监听，焦点在 input/textarea 时除外（`Shift+F` 除外）。 |
| **历史深度** | 保留最近 20 步可撤销操作。 | 超出 20 步时，移除最早的历史记录。 |
| **操作范围** | 任务/项目/里程碑的创建、删除、状态变更、移动、编辑、依赖增删。 | 导入/导出、主题切换、清除数据等不可逆操作不支持撤销。 |
| **Toast 反馈** | 撤销后顶部短暂显示“已撤销 [操作名]”（2.5秒），支持点击“重做”。 | Toast 可通过 ESC 提前关闭。 |
| **刷新后行为** | 撤销栈不持久化，刷新后清空。 | 首次刷新前弹窗提示“有未保存的撤销历史”（可选开启）。 |

### 2.3 主题系统

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **三种主题** | 浅色、深色、跟随系统（`prefers-color-scheme: dark`）。 | 默认跟随系统，首次使用浅色兜底。 |
| **实时切换** | 设置页切换后全局立即生效，无需刷新。 | 甘特图/依赖图的 Canvas/SVG 元素同步变色。 |
| **持久化** | 选择存入 IndexedDB `Settings` 表。 | |

### 2.4 首次使用隐私引导

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **触发条件** | 首次打开应用（无任何项目数据）。 | 后续可通过设置页底部链接重看。 |
| **内容** | 极简文案：“你的数据只在你手中。所有信息仅存储于本浏览器，绝不外传。” + 【开始使用】按钮。 | |
| **交互** | 点击按钮或按 Enter 关闭引导，进入空态驾驶舱。 | 引导浮层遮盖整个页面，背后为品牌过渡色。 |

### 2.5 离线就绪

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **资源加载后** | Service Worker 预缓存 HTML/CSS/JS 及关键字体。 | 断网刷新不出现空白页。 |
| **离线标识** | 断网时顶部出现浅灰提示条“当前网络不可用，数据仍在本地安全存储”。 | 重新连网后自动消失。 |


## 3. M02 驾驶舱

### 3.1 页面布局

驾驶舱为产品首页，信息按优先级自上而下排列：

```
┌─────────────────────────────────────────────┐
│  A. 风险雷达（置顶区）                       │
├─────────────────────────────────────────────┤
│  B. 今日必做                                │
├─────────────────────────────────────────────┤
│  C. 项目健康度矩阵        D. 即将到来的里程碑  │
├─────────────────────────────────────────────┤
│  E. 最近完成（可恢复）                       │
└─────────────────────────────────────────────┘
```

### 3.2 A区：风险雷达

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **数据来源** | 所有进行中项目的阻塞任务 + 所有逾期任务。 | 无阻塞、无逾期时显示空状态插画“一切尽在掌握”+ 子文案“所有项目均按计划推进”。 |
| **排序规则** | ①阻塞>48h（`escalated`）置顶；②逾期天数降序；③阻塞时长降序。 | 同一天数按项目创建时间升序（稳定排序）。 |
| **卡片信息** | 任务标题、所属项目名称、阻塞/逾期天数标签、优先级色点。 | `escalated` 任务标题前加 `⚠️ 急需介入`，卡片左侧红边脉冲动画。 |
| **SLA 升级条件** | `now - blockedAt > 48小时`。 | 阻塞任务被手动完成或取消阻塞后，退出雷达。 |
| **卡片点击** | 弹出任务详情浮层（同 M04c 组件），内可修改状态/依赖/备注。 | 浮层需在驾驶舱上下文内保持数据一致性。 |

### 3.3 B区：今日必做

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **筛选规则** | `dueDate` 为今日或已过去的待办/进行中任务，且状态非 `done`。 | 无任务时显示“今日无待办”+ 轻量插画。 |
| **排序** | 已逾期（天数降序）→ 今日截止 → 今日开始的进行中任务。 | |
| **卡片信息** | 任务标题、项目名称、截止时间（红色表示已逾期）、状态标签。 | |
| **点击** | 跳转至对应项目的看板视图，`URL: /projects/:id/board`。 | 若项目已归档/休眠，提示无法跳转并建议恢复项目。 |

### 3.4 C区：项目健康度矩阵

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **展示形式** | 2×N 网格，每个项目为一个色块卡片。 | 项目为奇数时最后一行仅一个居左；无进行中项目时显示“暂无活跃项目，去创建吧”+ 跳转按钮。 |
| **健康度判定** | 红灯：`逾期任务>0` 或 `关键路径上阻塞任务>0` 或 `逾期里程碑>0`；黄灯：`非关键路径阻塞>0` 或 `(已消耗工期占比 - 关键路径已完成任务数占比) > 10%`（偏差 = 关键路径已消耗工期占比 - 关键路径已完成任务数占比，分母为关键路径非done任务数）；绿灯：其余。 | 算法由 Web Worker 计算后缓存，打开驾驶舱即调用，非实时。 |
| **卡片信息** | 项目名、健康信号灯（红/黄/绿）、任务完成进度条（含锁定态）、阻塞计数徽标。 | 进度条遵循 M04a 的防欺骗规则。 |
| **hover 卡片** | Tooltip 显示风险摘要（最多 3 条，如“2个任务逾期”“1个关键路径阻塞”）。 | |
| **点击** | 跳转对应项目工作台。 | |

### 3.5 D区：即将到来的里程碑

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **时间范围** | `targetDate` 在未来 14 天内（含今天）且状态为 `pending`。 | 逾期里程碑进入风险雷达；无里程碑时显示“未来14天无里程碑”。 |
| **排序** | 按目标日期升序。 | |
| **卡片信息** | 里程碑标题、项目名、剩余天数（≤3天标黄，已逾期标红）、菱形图标（逾期红色+感叹号）。 | |
| **点击** | 跳转至对应项目的甘特图视图并高亮该里程碑。 | 项目中删除该里程碑后返回驾驶舱时不再显示。 |

### 3.6 E区：最近完成（可恢复）

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **数量** | 最近 10 条状态为 `done` 的任务，按 `completedAt` 降序。 | 无完成记录时隐藏此区域。 |
| **卡片信息** | 任务标题、项目名、完成时间（相对时间，如“2小时前”）。 | |
| **点击恢复** | 点击任务标题 → 任务状态变为 `todo` → 从完成列表移除 → 飞入对应项目的“待办”列。 | 恢复操作可撤销（`Ctrl+Z`）。 |


## 4. M03 项目全景

### 4.1 页面布局

页面顶部为三态 Tab：【进行中】【休眠】【归档】。下方为项目卡片网格（3列，≥1440px时）。

### 4.2 项目卡片

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **卡片内容** | 项目名称、健康颜色条（顶部横条）、任务进度（防欺骗百分比+状态图标）、待处理阻塞数徽章、最后更新时间。 | |
| **卡片操作** | 点击进入项目工作台；右键菜单：休眠/恢复/归档/删除。 | 删除有二次确认。 |
| **多选** | `Ctrl/Cmd + 点击` 多选，`Shift + 点击` 连续多选。 | 选中状态出现批量操作栏：批量休眠/归档/删除/导出。 |
| **空状态** | 进行中为空时引导“创建你的第一个项目”；休眠/归档为空时展示对应提示插画。 | |

### 4.3 休眠与归档

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **休眠** | 休眠项目不参与驾驶舱统计、不触发逾期报警、不在待办桌显示；可在项目全景的“休眠”Tab找到并恢复。 | 恢复后历史数据全部保留。 |
| **归档** | 归档项目仅可查看，不可编辑。归档项目不计入任何实时统计。 | 可通过“数据与档案”完全删除或重新激活。 |

### 4.4 创建项目

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **入口** | 项目全景右上角【+ 新建项目】按钮。 | |
| **表单字段** | 项目名称（必填）、描述（可选 Markdown）、颜色标签（可选 8 种预设色）。 | 名称为空时按钮置灰。 |
| **确认** | Enter 键提交或点击按钮，项目出现并进入工作台。 | |


## 5. M04 项目工作台

### 5.1 工作台头部

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **项目信息** | 项目名称（可点击编辑）、健康信号灯（实时）、进度条（防欺骗）、阻塞/逾期摘要。 | |
| **视图切换** | 【看板】【甘特图】切换按钮。 | URL同步：`/projects/:id/board` 和 `/projects/:id/gantt`。 |
| **面包屑** | 项目全景 > 项目名。 | 点击返回项目全景。 |

### 5.2 M04a 看板视图

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **列定义** | 四列：待办（todo）、进行中（in_progress）、阻塞（blocked）、完成（done）。 | 列宽等比分配，支持水平滚动（列内容长时）。 |
| **阻塞列强化** | 列背景 `#FFF3E0`（浅橙，深色模式对应加深），列头图标 `⚠️` + 阻塞任务计数。 | |
| **卡片信息** | 任务标题、优先级标签、截止日期、标签色块、是否有关键路径标识（红色菱形小图标）。 | 逾期截止日期红色显示。 |
| **拖拽** | 卡片可在列间拖拽更改状态（使用 @dnd-kit），产生平滑过渡动画。 | 拖拽到阻塞列时弹出原因输入框；完成列自动记录完成时间。 |
| **进度条（项目级）** | 在列头上方显示总进度条，遵循 M04b 防欺骗规则。 | |
| **空列** | 各列空时显示对应提示：“暂无待办任务”等。 | |
| **添加入口** | 每列底部有“+ 添加任务”按钮，点击后出现内联输入框。 | 也支持通过快速指令栏创建。 |

### 5.3 M04b 甘特图视图

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **时间轴** | 默认显示当前月 ± 1 个月，可通过滚轮缩放（日/周/月）和拖拽平移。 | 今天用红色竖线标记。 |
| **任务条** | 图形化展示任务的时间区间（`startDate`–`dueDate`），颜色与项目颜色一致。 | 已完成任务加删除线或半透明。 |
| **依赖线** | 前置任务末尾连接后置任务开头，箭头指向。关键路径依赖线为红色加粗。 | 循环依赖检测并提示无法创建。 |
| **拖拽创建依赖** | 鼠标从一任务条末端拖至另一任务条起始端，释放后创建前置依赖。 | 被拖拽任务必须是后置任务（箭头指向）。 |
| **手动添加依赖** | 通过任务详情浮层搜索添加（见 5.4）。 | |
| **里程碑** | 菱形标记在对应日期，逾期为红色+感叹号，已完成变为实心。 | |
| **关键路径开关** | 右上角持久显示 `🔴 关键路径` 切换按钮。开启时仅高亮关键路径任务。 | 关键路径变更时按钮旁出现刷新动画（1.5秒）。 |
| **阻塞标记** | 甘特条上叠加 ⚠️ 条纹纹理，hover 显示阻塞原因。 | |

### 5.4 M04c 任务详情浮层

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **触发方式** | 点击看板卡片 或 甘特图任务条 或 驾驶舱雷达卡片。 | 浮层为侧边栏形式（≥1440px）或居中模态（<1440px）。 |
| **可编辑字段** | 标题、描述（Markdown）、优先级、负责人、开始/截止日期、预估工时、标签、状态。 | 所有修改即时保存（debounce 500ms 后写入 IndexedDB）。 |
| **阻塞管理** | 状态改为阻塞时必填阻塞原因；可记录阻塞开始时间（自动或手动）。 | 解除阻塞时需确认，自动清空阻塞字段。 |
| **依赖管理** | 展示前置/后置任务列表，支持搜索项目内任务并添加为依赖。 | 自动过滤自身和已存在依赖。 |
| **依赖网络图** | 浮层底部小型节点图（React Flow），展示该任务的直接前后置任务。 | 节点上可点击跳转对应任务详情。 |
| **Audit 时间线** | 底部“变更历史”Tab，展示该任务最近 20 条 ChangeLog，倒序排列。 | |
| **删除** | 浮层工具栏【删除】按钮，二次确认后删除并移除所有关联依赖。 | 可撤销恢复。 |

### 5.5 快速指令栏

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **位置** | 工作台头部下方/左上方固定位置，键盘焦点可通过 `/` 键（非输入框焦点时）快速激活。 | |
| **语法** | `任务标题 #标签 @负责人 ~截止日期 !优先级`。示例：`设计评审 #UI @张三 ~2026-05-01 !高`。 | 解析器在输入时实时解析，底部预览浮层显示解析结果。 |
| **连续创建** | 浮层“连续创建”开关，开启后确认创建不清空指令栏（仅清空标题），关闭则清空整栏。 | 默认关闭。 |
| **错误提示** | 无法解析的字段在预览中高亮但不阻断创建。 | |


## 6. M05 个人待办桌

### 6.1 核心功能

| 功能点 | 规格描述 | 边界与异常 |
|:---|:---|:---|
| **数据来源** | 所有进行中项目、状态为 `todo` 或 `in_progress` 的任务，按截止日期和优先级排序。 | 无任务时显示“没有待办，去驾驶舱看看”+ 跳转按钮。 |
| **筛选器** | 顶部快速筛选：全部 / 已逾期 / 今日 / 本周 / 阻塞中；可叠加项目筛选。 | 选择“阻塞中”仅显示阻塞态任务。 |
| **任务卡片** | 标题、项目标签、截止日期、优先级、阻塞标记。 | 点击跳转对应项目工作台。 |
| **行内操作** | 每项左侧有快速勾选框，勾选后标记完成（带划掉动画）。 | 完成操作可撤销。 |

## 9. 全局功能规范补充

### 9.1 键盘操作

| 快捷键 | 作用范围 | 行为 |
|:---|:---|:---|
| `Ctrl+Z` | 全局（输入框除外） | 撤销上一步操作 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 全局（输入框除外） | 重做 |
| `Delete` | 选中任务/项目/里程碑时 | 删除选中项（需确认） |
| `Enter` | 表单/快速指令栏 | 提交/确认 |
| `Esc` | 浮层/模态/专注模式 | 关闭浮层 / 退出模式 |
| `/` | 项目工作台（非输入框） | 聚焦快速指令栏 |
| `Shift+F` | 个人待办桌 | 切换专注模式 |

### 9.2 空状态规范

所有列表、区域在无数据时必须展示：
- 与场景匹配的插画或图标。
- 一句清晰的说明文案。
- 一个主要操作 CTA 按钮（如“创建任务”）。

### 9.3 全局 Toast

- **位置**：视口顶部居中或右上角。
- **时长**：普通 2.5 秒，包含操作按钮（如“撤销”）的为 5 秒。
- **类别**：成功（绿）、警告（黄）、错误（红）、信息（蓝）。

### 9.4 加载态

- **关键路径计算**：进度条或指标显示骨架屏闪烁，不阻塞用户继续浏览和操作其他区域。
- **甘特图初次渲染**：显示时间轴骨架，任务条逐步显现。

### 9.5 数据一致性校验

- **循环依赖检测**：添加依赖时检查是否形成循环，是则拒绝并提示“无法创建循环依赖”。
- **阻塞状态变更**：从 `blocked` 改为其他状态时，强制清空 `blockedReason` 和 `blockedAt`。
- **里程碑状态**：里程碑关联的所有任务完成时，提示是否将里程碑标记为 `achieved`（可手动延迟）。
